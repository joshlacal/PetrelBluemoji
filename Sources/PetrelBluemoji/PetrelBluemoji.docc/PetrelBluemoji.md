# ``PetrelBluemoji``

Generated AT Protocol lexicon types for Bluemoji custom emoji, layered on the Petrel core SDK.

## Overview

PetrelBluemoji is a Swift package for iOS 18 and macOS 15, part of the Catbird / Petrel family. Source and issues live at [github.com/joshlacal/PetrelBluemoji](https://github.com/joshlacal/PetrelBluemoji).
